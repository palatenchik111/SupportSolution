# Архитектура и модули

| Модуль | Ответственность | От чего зависит | Почему |
|---|---|---|---|
| **Support.Domain** | Предметные сущности, бизнес-правила | Ни от чего | Ядро системы. Не должно знать о базе данных или HTTP. |
| **Support.Application** | Контракты, интерфейсы, сценарии | Domain | Определяет "что" нужно делать, используя язык Domain. |
| **Support.Infrastructure** | Технические детали (БД, кэш, API) | Application, Domain | Реализует контракты Application. Зависит от Domain, т.к. оперирует его сущностями. |
| **Support.WebApi** | HTTP-интерфейс, маршрутизация | Application, Infrastructure | Точка входа. Настраивает DI (связывает Application и Infrastructure). |
| **Support.UnitTests** | Проверка бизнес-логики | Domain | Тестирует чистую логику без зависимостей от инфраструктуры. |
